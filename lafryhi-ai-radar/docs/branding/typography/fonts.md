# Official Typography

**Version:** 1.0

## Primary Typeface

Use **Inter** for new designed brand materials when licensing and delivery permit. Inter provides a neutral, highly legible, professional voice suitable for product interfaces, social graphics, presentations, and editorial communication.

Recommended weights:

- 800 — major headlines and compact wordmark-style display.
- 700 — section headings, labels, and calls to action.
- 600 — subheadings and emphasized UI text.
- 400 — body copy.

## Digital Fallback Stack

```css
font-family: Inter, Arial, "Helvetica Neue", Helvetica, sans-serif;
```

This documentation defines the brand standard; it does not authorize an application-code change. Existing product typography should be migrated only through a separately reviewed product task.

## Hierarchy

| Level | Guidance |
| --- | --- |
| Display | Bold, compact, sentence case, short line length |
| Heading | Clear hierarchy with generous spacing |
| Body | Regular weight, comfortable line height, readable measure |
| Label | Semibold or bold, concise, optional uppercase with restrained tracking |
| Metadata | Smaller but still accessible; use Muted Blue-Gray carefully |

## Writing and Typesetting

- Use sentence case for headlines.
- Preserve the product spelling **LAFRYHI AI Radar**.
- Do not set long paragraphs in uppercase.
- Avoid excessive letter spacing in body copy.
- Keep line lengths approximately 45–80 characters where practical.
- Use real typographic punctuation and consistent numerals.
- Prioritize readability over visual novelty.

## Unsupported Styles

Do not use:

- Decorative sci-fi or “computer” fonts.
- Condensed type for body copy.
- Script or handwritten display styles.
- Artificial outlines, bevels, or glow around text.
- Multiple competing type families in one composition.
