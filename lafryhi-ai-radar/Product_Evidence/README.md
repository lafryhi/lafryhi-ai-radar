It contains project-verifiable facts and genuine captures from the live product, authenticated operator workspace, authenticated Google Cloud account, public repository, and public demo video.

## Evidence handling

1. Capture evidence during the hackathon period and retain the original files.
2. Use readable timestamps and show the Google Cloud project/service context where relevant.
3. Redact secrets, access tokens, personal data, billing account numbers, customer contact details, and unrelated project data.
4. Do not mark an item complete until its URL or artifact has been opened and independently checked.
5. Obtain user consent before sharing testimonials or identifiable user information.

The official rules remain authoritative: <https://xprize.devpost.com/rules>.
