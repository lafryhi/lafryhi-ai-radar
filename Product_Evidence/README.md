## Why the original binary assets are not blindly restored here

The historical production-evidence commit also contained screenshots and a PDF. This final-submission branch restores the textual evidence first so every claim can be reviewed and dated. Binary screenshots/PDF should only be restored or replaced after a final privacy and freshness check; old captures should not be presented as if they prove the current state at the deadline.

## Evidence rule

No fabricated evidence. Testnet activity is not revenue. Dated production captures remain dated. Private customer/financial evidence belongs in the appropriate judging channel rather than this public repository.
