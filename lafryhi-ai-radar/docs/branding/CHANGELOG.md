# Branding Changelog

All approved changes to the LAFRYHI AI Radar visual identity are recorded here.

The format follows semantic versioning:

- **Major:** fundamental identity change or incompatible replacement.
- **Minor:** approved extension, new asset class, or meaningful guideline addition.
- **Patch:** correction that does not change identity intent.

## 1.0.0 — 2026-07-29

### Added

- Official branding repository structure.
- Primary LAFRYHI AI Radar logo reference.
- Social profile-picture reference.
- Facebook cover reference.
- LinkedIn cover reference.
- Social-post template reference.
- Consolidated brand-kit visual reference.
- Brand guidelines, color palette, and typography standards.
- Governance rule declaring `reference/` the single source of truth.

### Identity Definition

- Established the radar, signal, evidence, verification, and forward-decision visual language.
- Established Deep Navy, Signal Blue, Verification Green, White, and Muted Blue-Gray as the official palette.
- Established a calm, professional, evidence-based visual tone.
