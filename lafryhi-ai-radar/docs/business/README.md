# Go-To-Market Documentation

**Version:** 1.0  
**Created:** 2026-07-29

This directory is the commercial and strategic operating reference for the LAFRYHI AI Radar Go-To-Market Phase. It exists to align customer discovery, acquisition, measurement, launch activity, and product prioritization around real user evidence.

The repository's technical documentation explains how the product is designed, built, secured, tested, and operated. The documents here explain who the product serves, how it creates and communicates value, how the team will reach customers, and how market evidence will guide what happens next. These two documentation layers are complementary; this directory does not replace or redefine the technical record.

## Operating Rule

> No major feature should be built unless user evidence demonstrates a real need.

These documents are living operating references. Updates should cite new behavioral, interview, retention, or revenue evidence and be recorded in the [Decision Log](./DECISION_LOG.md) when they materially change strategy.
